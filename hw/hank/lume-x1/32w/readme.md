# Hank Lume-X1 32W (70% power)

This is the same as the &hank-lume-x1, but with maximum power limited to
about 70% (which should be about 32W, in theory).

Lights with weaker LEDs ship with this, or you may want to install it even on
stronger lights to reduce the turbo brightness and heat.  Most of these
lights are overpowered anyway, so a lower limit can be nice.

If your ramp has a "bump" or a "dip" in it, adjust the GEARCHANGE value.
